PART 1 · 熱身：Exercise 工作表

1WEEKDAY 日期是星期幾

C3
=WEEKDAY(B3,2)

第二個參數 Return_type：1 → 星期日 = 1；2 → 星期一 = 1 … 星期日 = 7。用 2 時 > 5 就是星期六、日，第 11 步會用到。

2TEXT 把數值變成指定格式的文字

在 C7 至 C11 輸入公式，結果要和 D 欄 ANS 一樣：

格公式結果
C7=TEXT(B7,"DDD")Tue
C8=TEXT(B8,"DDDD")Tuesday
C9=TEXT(B9,"MM/DD/YY")09/28/21
C10=TEXT(B10,"$###,###,###")$12,345,678
C11=TEXT(B11,"(##)####-####")(12)3456-7898
注意：影片中 B11 是 11 位數字，所以用 (###)。你的檔案 B11 是 10 位（1234567898），括號內只要 2 個 #。

3MATCH 找出位置

C22
=MATCH(B22,C17:C20,0)

40 在 C17:C20 的第 3 個位置。最後的 0 = 完全相同；找不到會出現 #N/A。第 12 步用它找假期。

4IFERROR 出錯時顯示別的內容

C27
=IFERROR(4/0,"Error")

4/0 會出現 #DIV/0!，用 IFERROR 改為顯示 Error。第 9 步會用它處理月尾的空白格。

  3. Mac 版：Excel › Preferences › Ribbon & Toolbar，勾選 Developer。

上方會多了「開發人員」，之後的調節鈕和巨集都在這裏。

8每月第一日 DATE

C3
=DATE(C1,I1,1)

只顯示「日」：Right-click（右鍵）→ Format Cells › Number › Custom 影片：儲存格格式 › 數值 › 自訂，Type （類型） 輸入 d → OK。

9第 2 日至第 31 日 IFERROR + IF + MONTH

影片先試 =C3+1，再把月份改成 2 月，發現 3 月 1、2、3 日都跑了出來，所以改為：

D3
=IFERROR(IF(MONTH(C3+1)=$I$1,C3+1,""),"")

D3 向右拖曳到 AG3，再設格式 d。

IF：下一日仍是同一個月才顯示，否則留空。IFERROR：前一格已是空白時，""+1 會出錯，改為留空。$I$1 要加 $，拖曳時才不會移位。

10星期 TEXT

C4
=TEXT(C3,"DDD")

C4 向右拖曳到 AG4。按調節鈕換月份，星期會跟着改。

11週末標色 Conditional Formatting + WEEKDAY

  1. 選取 C3:AG30（由 C3 開始選）。
  2. Home › Conditional Formatting › New Rule 影片：常用 › 設定格式化的條件 › 新增規則
  3. 選 Use a formula to determine which cells to format （影片：使用公式來決定要格式化哪些儲存格），在 Format values where this formula is true 輸入：
規則
=WEEKDAY(C$3,2)>5

Format… › Fill → 淺橙色 → OK → OK。（影片：格式 › 填滿 › 確定）

C$3：鎖第 3 列、不鎖欄。每一格都看自己那一欄的日期，所以整欄一起變色。

12公眾假期標色 Conditional Formatting + MATCH

先到 Table 工作表看看：D 欄是 2026 年澳門公眾假期日期（D2:D29）。回到出勤表，同樣選取 C3:AG30，新增規則：

規則
=MATCH(C$3,Table!$D$2:$D$29,0)>0

Format… › Fill → 深紅色 → OK → OK。按調節鈕到 1 月：1 日元旦整欄變紅。

注意：影片用 2021 年的表（$D$1:$D$20）。你的檔案假期在 $D$2:$D$29，範圍要改。

13班別下拉清單 Data Validation

  1. 選取 C6:AG30。
  2. Data › Data Validation 影片：資料 › 資料驗證 → Settings › Allow: List （影片：儲存格內允許：清單）。
  3. Source （來源） 輸入（或到 Table 工作表選 A2:A9）→ OK：
來源
=Table!$A$2:$A$9

14班別顏色 3 條規則

選取 C6:AG30 → Home › Conditional Formatting › New Rule › Use a formula…，新增 3 條規則，每條按 Format… › Fill 選顏色：

=C6="overtime"
=C6="day off"
=RIGHT(C6,5)="leave"
RIGHT(C6,5) 取最後 5 個字：sick leave、personal leave、official leave 都以 leave 結尾，一條規則就夠。
常見錯誤：在對話框用滑鼠點 C6，Excel 會自動變成 $C$6（影片 21:20），要刪去 $ 改回 C6，否則整片只看 C6 一格，顏色全錯。

15Clear 按鈕 錄製巨集 Macro

  1. Developer › Record Macro 影片：開發人員 › 錄製巨集，Macro name （巨集名稱） 輸入 clear → OK。
  2. 選取 C6:AG30 → 按 Delete。
  3. Developer › Stop Recording 影片：開發人員 › 停止錄製。
  4. Developer › Insert › Form Controls › Button 影片：開發人員 › 插入 › 表單控制項 › 按鈕，在 K1:L1 畫一個 → Assign Macro （指定巨集） 選 clear → OK → Right-click › Edit Text 改為 Clear。

隨便選幾個班別，按 Clear 測試。

16儲存及提交 Save as .xlsm

  1. File › Save As 影片：檔案 › 另存新檔
  2. Save as type: Excel Macro-Enabled Workbook (*.xlsm) （影片：存檔類型：Excel 啟用巨集的活頁簿）
  3. 檔名：Class_Number_Name.xlsm（例如 F5A_05_ChanTaiMan.xlsm）
注意：存成 .xlsx 巨集會被刪除，Clear 按鈕便不能用。
